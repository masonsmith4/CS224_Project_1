2. Project 1 Description:

CompanyBSU just has 100,000  employees.

CompanyBSU now needs to count the age of their employees. The youngest employee is 20 years old, and the oldest is 65 years old.

The employee information will be given in csv files for companyBSU. The information is extracted from a database (Jeff Zhang made it.), and it has the following attributes for the employee: id, first_name, last_name, age. They are sorted by employee ID.

CompanyBSU wants the information to be sorted by employees’ ages, so they can easily count the number of employees in different age intervals. To make sure the result is correct, CompanyBSU wants to use six different sorting algorithms to generate the results.

3. Project 1 Requirement:

1). Use 6 different sorting algorithms to sort the given data file by employee age. Implement bubble sort, selection sort, insertion sort, merge sort, quick sort and heap sort in Java programming language.

2). The original information should not be changed. Only the order of the entries should be changed if necessary.

3). Record the time for running each algorithm (bubble sort, selection sort, insertion sort, merge sort, quick sort and heap sort).

4). After sorting, output the result to a csv file with the same format with the given data file. The six output files (sorting by age) names are: companyBSU_BubbleSort.csv, companyBSU_InsertionSort.csv, companyBSU_MergeSort.csv, companyBSU_QuickSort.csv,  companyBSU_SelectionSort.csv, and companyBSU_HeapSort.csv

5). Submit your Project1 as zip folder to Canvas.

Write a simple report on the running times for six algorithms (bubble sort, selection sort, insertion sort, merge sort, quick sort and heap sort).
Observe if the sorting algorithm is stable or not. Write your conclusion to the report and state why the algorithm is stable or not.
